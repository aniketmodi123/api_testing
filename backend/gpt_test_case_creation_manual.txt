## Templates

* **Create/Update success**

```json
{ "status": 201, "json": { "checks": [ { "path": "response_code", "equals": 201 }, { "path": "errors", "absent": true } ] } }
```

* **Validation error (422 / 400)**
  *FastAPI returns a `detail[]` array; test must check inside it.*

```json
{ "status_in": [400,422], "json": { "checks": [ { "path": "detail[0].loc[0]", "equals": "query" }, { "path": "detail[0].msg", "equals": "Field required" } ] } }
```

* **GET list**

```json
{ "status_in": [200,206], "json": { "either": [
  { "checks": [ { "path": "response_code", "equals": 200 }, { "path": "errors", "absent": true }, { "path": "data", "present": true } ] },
  { "checks": [ { "path": "response_code", "equals": 206 }, { "path": "error_message", "contains": "No Data Found" }, { "path": "data", "absent": true } ] }
] } }
```

* **GET by id**

```json
{ "status_in": [200,206], "json": { "either": [
  { "checks": [ { "path": "data", "length": 1 }, { "path": "data[0].id", "type": "number" } ] },
  { "checks": [ { "path": "response_code", "equals": 206 }, { "path": "error_message", "contains": "No Data Found" } ] }
] } }
```

* **Not found**

```json
{ "status": 206, "text_contains": "No Data Found", "json": { "checks": [ { "path": "response_code", "equals": 206 }, { "path": "error_message", "contains": "No Data Found" }, { "path": "data", "absent": true } ] } }
```

* **Invalid query**

```json
{ "status": 422, "json": { "checks": [ { "path": "detail[0].loc[1]", "equals": "id" }, { "path": "detail[0].msg", "present": true } ] } }
```

* **Unauthorized (invalid token)**

```json
{ "status": 401, "text_contains": "Invalid token", "json": { "checks": [ { "path": "response_code", "equals": 401 }, { "path": "error_message", "equals": "Invalid token" }, { "path": "data", "absent": true } ] } }
```

## Test Case Format

1. Every test case = **single JSON object**, never multiple snippets.
2. Structure:

```json
{
  "name": "Test Case Name",
  "headers": { ... },   // only when overriding defaults
  "params": { ... },    // required query params must always be included
  "body": { ... },
  "expected": { ... }
}
```

3. Common headers (e.g., `Content-Type`, `username`, `vertical`) are **globally configured**.

   * Only include `headers` inside a test when **different from defaults**.

---

## Validation Rules

4. Always include required query params.
5. For **GET APIs**, use `status_in: [200,206]`.

   * `200` → data returned
   * `206` → no data found
   * **200 never comes alone**.
6. Use `status` or `status_in`, never both.
7. Always include at least one `text_contains` or `json.checks`.
8. Mirror `response_code` to HTTP status unless disabled.
